# Mochi animated face

The face uses two independently drawn, rounded green eye blocks at 240×240 resolution. It is an **original simple drawing**, not a copy of FluxGarage RoboEyes code. Normal READY mode blinks; LISTENING/THINKING/UPLOADING are labeled; SPEAKING currently freezes the eye drawing during playback because TFT writes were observed to interrupt audio output on the prototype.

Future states (happy, tired, curious) will be driven by actual model messages only when implemented and measured. Original FluxGarage RoboEyes is GPL-3.0; see docs/LICENSING.md before integrating code from it.
